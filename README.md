# COSMIA ✦

**Created by Waywhales**

COSMIA — дневник заботы о теле, душе и внутренней гармонии, созданный Waywhales. Статическое PWA-приложение на русском языке.

## Публикация
В GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. После публикации адрес будет иметь вид `https://waywhales-code.github.io/Waywhales/`.

## Возможности
- Профиль с именем и фото (фото сжимается перед локальным сохранением)
- Добавление, редактирование, удаление добавок и отметки приёма
- Календарь, недельная статистика и экспорт JSON
- Установка как PWA при открытии по HTTPS

## Ограничения
Данные хранятся локально в браузере и не синхронизируются между устройствами. Уведомление в этой версии возможно только пока приложение открыто; фоновые push-уведомления требуют серверной инфраструктуры. Приложение не назначает дозировки и не заменяет врача.
