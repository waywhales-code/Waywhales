# COSMOS ✦

**Created by Waywhales**

COSMOS — дневник заботы о теле, душе и внутренней гармонии, созданный Waywhales. Статическое PWA-приложение на русском языке.

## Публикация
В GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. После публикации адрес будет иметь вид `https://waywhales-code.github.io/Waywhales/`.

## Возможности
- Профиль с именем и фото (фото сжимается перед локальным сохранением)
- Добавление, редактирование, удаление добавок и отметки приёма
- Календарь, недельная статистика и экспорт JSON
- Установка как PWA при открытии по HTTPS

## Уведомления PWA

- COSMOS может отправлять одно ежедневное push-напоминание в выбранное пользователем время.
- Для фоновой доставки используется отдельный Cloudflare Worker и Cloudflare D1. Существующий AI Worker не изменяется.
- На iPhone push доступен для веб-приложения, добавленного на экран «Домой», на iOS/iPadOS 16.4 и новее. На Android используйте актуальный Chrome или совместимый браузер.
- Пользователь должен явно разрешить уведомления. Их можно отключить в профиле COSMOS или в настройках устройства.
- В D1 хранятся endpoint подписки, ключи шифрования Web Push, часовой пояс и выбранное время. Названия добавок, дозировки, фотографии, заметки и история отметок не передаются.
- Доставка зависит от поддержки браузера, разрешений устройства, подключения к сети и ограничений операционной системы; гарантировать точное время получения нельзя.

Исходники push-сервиса и схема его базы находятся в `cloudflare/cosmos-push/`. VAPID private key должен храниться только как Cloudflare Worker Secret `VAPID_PRIVATE_JWK` и не должен попадать в Git.

## Ограничения
Данные хранятся локально в браузере и не синхронизируются между устройствами. Уведомление в этой версии возможно только пока приложение открыто; фоновые push-уведомления требуют серверной инфраструктуры. Приложение не назначает дозировки и не заменяет врача.
